# Demo media

- `between-demo.mp4`: existing 22-second product walkthrough, H.264/AAC, 1920 × 1080 at 30 fps. The video simplifies and enlarges the UI for presentation.
- `between-demo.gif`: 720-pixel-wide, 8 fps silent version for the README, about 1 MB.
- `between-poster.jpg`: poster from the walkthrough's evidence scene.
- `01` through `06`: actual local application screenshots. Desktop captures use a 1440 × 960 layout; mobile uses 390 × 844.

All conversations are fictional. Reviews in screenshots are illustrative fixtures, not live provider results. New real workspaces start empty. No API key or production workspace was used for capture.

The exported video was reused from the existing project media. Its asset notes credit “Happy Beats Business Moves, Vol. 12” by ende.app for music and Kenney sound effects. Source audio is not redistributed separately. Manrope and Source Sans 3 are included in the application with their font licenses in `public/fonts/`. The application mark is the project's existing mark.
